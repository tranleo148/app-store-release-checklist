# Mobile release checklists

[Tiếng Việt](../index.md) · **English**

Checklists for a first store release of a mobile app, built from real releases. Each one comes in Vietnamese
and English and can be downloaded as `.md`.

- **[App Store (iOS)](../app-store/en.md)**: from the Apple Developer account, Xcode and TestFlight to App
  Review and after go-live.
- **[Google Play (Android)](../google-play/en.md)**: from Play Console, signing, the R8 build and Data safety
  to closed testing, production and staged rollout.
